# Imported source material: tiling labs and repair textbook

## Goal

Three artifacts were imported into this ticket's `sources/` directory on 2026-08-28 from
`~/Downloads`. They are the reference implementations and the theory for the rebalancing
modal. This document maps them so you don't have to re-read everything to find one function.

## Context

- The labs are **single-file, dependency-free HTML** prototypes. Open them directly in a
  browser (`xdg-open sources/repair-lab-2.html`). No build step.
- They model layouts as **n-ary split trees** (`{t:'p'|'s'|'k'}` with weight vectors), which
  is NOT pbui's representation (binary `Split` with one `ratio`). The design guide
  (design-doc/01, Part III) covers the adapter.
- The textbook's numbers were generated by the repair-lab code at its reference config
  (screen 1072×656, min 190×130, gap 8, tabH 14, aspect 1.40 — §1.10). Use them as test
  fixtures.

## Usage Examples

- Porting RIPPLE: open repair-lab-2 `stratRipple`, read textbook §4 alongside; the COMPOUND
  trace in §4.2 is your integration test's expected shape.
- Verifying projectLower: `projectLower([.5,.3,.2],[.25,.35,.10]) → [.4750,.3500,.1750]`
  (§5.2) — copy as a unit test.
- Checking slate behaviour: load `HEALTHY` in the lab → exactly one card ("LEAVE AS IS
  +7 agree"). Your `buildSlate` on the equivalent pbui fixture must do the same.
